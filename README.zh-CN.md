# rag-table-ai

**让 RAG 召回一行数据时，也能召回解释它的表头。**

[English](README.md) · [快速开始](#快速开始) · [运费示例](examples/03_shipping_rates.py)

`rag-table-ai` 是一个轻量 Python 库。它把管道表格切成自带列名的分片，也能将每行展开为带字段名的文本、判断数值是否落在区间内，以及求值受支持的算式。核心无运行时依赖，无需调用大模型。

**示例问题：**15 kg 的货物走加急，打八折后多少钱？

```text
普通切片
  | 11–20 kg | 12.00 | 18.00 |
  哪个数字是加急价？

带表头的切片
  | 重量（整 kg） | 普通（USD） | 加急（USD） |
  | 11–20 kg     | 12.00      | 18.00      |
  加急：18.00 × 80% = 14.40 USD
  来源：shipping-rates，表内第 2 条数据行
```

## 快速开始

需要 Python 3.9 或更高版本。下面的示例会匹配运费档位、读取加急价并计算折后价。

```bash
git clone https://github.com/jakelihua/rag-table-ai.git
cd rag-table-ai
python -m pip install .
python examples/03_shipping_rates.py
```

Python 调用见 [Quickstart](README.md#quickstart)。调用方提供待匹配的重量、目标列和折扣。

## 如何接入 RAG

1. 将抽取好的管道表格交给 `split_table()`。用分片的 `markdown_text` 建索引，让检索文本带有列名。另存 `metadata`，用于引用表格与表内行号。
2. 用 `flatten()` 生成带字段名的阅读视图。它有行数上限，完整入库请使用切片。有关键词命中时，优先保留命中行，再补相邻行。
3. 用 `match()` 判断给定数值是否落在某个区间，用 `calculate()` 计算受支持的算式。命中多个区间时，由调用方报告歧义或按业务规则选择。

| 能力 | 当前支持范围 |
| --- | --- |
| 表格输入 | 单层表头，或按[示例约定](examples/01_quickstart.py)填写的双层表头。父级的空白单元格沿用左侧父级名称。PDF、图片和 HTML 交给上游抽取。 |
| 切片 | 按数据行数切分，每片重复解析后的列名，并记录从 1 开始的表内数据行范围（含首尾）。超宽数据行抛出 `ValueError`，短行在右侧补空。 |
| 区间匹配 | 支持带正负号的整数和小数闭区间。显式单位须一致，裸数字沿用区间单位。输入为 `15 kg` 这样的数值或文本标签。 |
| 算式求值 | 支持受限的 Decimal 算式、百分号和常见全角运算符。调用方提供表达式，并按自己的业务规则校验输入格式和舍入行为。 |

## 如何评估

运费示例用于复现一次表头保留和查价。做检索评测时，先看前几个结果能否给出**正确单元格及对应列名**。用相同的召回与上下文预算比较普通文本切片和已有的重复表头方案。核心处理耗时、索引文本体积及下游上下文 token 分别报告。

遇到丢表头或匹配错档位的案例，欢迎提交一个脱敏后的最小表格、查询和预期命中的行列。
